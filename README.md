# EMWA Website

A modern, responsive HTML website for EMWA with clean design and interactive features.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Interactive Navigation**: Smooth scrolling navigation with fixed header
- **Contact Form**: Functional contact form with validation
- **Service Showcase**: Grid layout for displaying services
- **Cross-browser Compatible**: Works on all modern browsers

## Files Structure

```
├── index.html      # Main HTML file
├── styles.css      # CSS styles and responsive design
├── script.js       # JavaScript functionality
└── README.md       # Project documentation
```

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. The website is ready to use!

## Customization

### Content
- Edit `index.html` to update text content, sections, and structure
- Modify the navigation links, hero section, about section, services, and contact information

### Styling
- Update `styles.css` to change colors, fonts, layouts, and responsive breakpoints
- The CSS uses CSS Grid and Flexbox for modern layouts
- Color scheme can be easily modified by changing the CSS custom properties

### Functionality
- Modify `script.js` to add or change interactive features
- Current features include smooth scrolling, form validation, and scroll animations

## Sections

1. **Header/Navigation**: Fixed navigation bar with smooth scrolling links
2. **Hero Section**: Eye-catching banner with call-to-action button
3. **About Section**: Information about EMWA
4. **Services Section**: Grid layout showcasing services
5. **Contact Section**: Contact form with validation
6. **Footer**: Simple footer with copyright information
